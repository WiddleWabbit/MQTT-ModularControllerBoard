class

SensorManager

Owns all sensor hardware (ultrasonic, IMU, etc.). Provides a clean interface for reading distances and detecting obstacles. Initialised once in setup().
begin () ▶
Initialises I2C/SPI buses and runs a short self-test on each sensor.
Returns
  • bool — true if all sensors responded
readDistance (uint8_t sensorId) ▶
Returns the latest distance reading in centimetres.
Arguments
  • sensorId — index of the ultrasonic sensor (0–3)
Returns
  • float — distance in cm, or -1.0 on error
isObstacle (float thresholdCm = 30.0f) ▶
True when any forward-facing sensor reports a value below the threshold.
Arguments
  • thresholdCm — distance under which an obstacle is declared
class

MotorController

Handles PWM output to the left and right motor drivers. Responsible for speed limiting and soft-start ramping.
begin () ▶
Configures PWM channels and sets default speed limits.
drive (int left, int right) ▶
Writes constrained PWM values to both motors.
Arguments
  • left — desired left speed (−255 … 255)
  • right — desired right speed (−255 … 255)
class

Clock

Thin wrapper around millis() / micros() that provides a monotonic timestamp used throughout the control loop.
now () ▶
Returns milliseconds since boot.
Returns
  • uint32_t
class

Adapter

Bridge between the high-level state machine and the hardware drivers. Handles configuration handshakes and keeps the last successful config time.
configure (const Config& cfg) ▶
Applies a new configuration packet to the underlying drivers.
Arguments
  • cfg — configuration structure (gains, limits, etc.)
enum / state

State

High-level control states used by the main loop state machine. Typical values: Idle, WaitingForSync, Running, Error.
